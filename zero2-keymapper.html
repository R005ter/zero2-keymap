Install

  1. Save the file to ~/.config/karabiner/assets/complex_modifications/
  2. Karabiner-Elements → Complex Modifications → Add rule → enable it
  3. Make sure the Zero 2 is enabled under the Devices tab

One-click import — hosted config URL:

karabiner://…

Imports the hosted file at that URL — not the unsaved tweaks above. For a customized layout, use Copy / Download and the manual steps. The hosted file's device IDs are preset for the Zero 2, so the import works out of the box.
