8BitDo Zero 2 — one-hand cheat sheet

D-pad · thumb face · thumb triggers · fingers

↑ ↓ ← →Arrow keysthumb

Navigate Claude Code — menus, options, history. Real arrow-key presses, so they work everywhere.

i · tapFlip to last appthumb

⌘Tab — bounce between your two most-recent apps. Need something deeper in the stack? Hold m instead.

j · holdPush-to-talkthumb

Holds Ctrl+Opt for Wispr Flow — speak while held, release and the text drops in. Quick bursts; it ties up the thumb, so for talk-while-navigating use hands-free.

g · tapLaunch / focus Terminalthumb

Jumps you home from anywhere — opens Terminal if it isn’t running, focuses it if it is.

k · tapWispr hands-freeindex

Fn+Space — toggle always-on dictation. Tap again to stop. Hands stay free, so you can talk and steer the D-pad at the same time.

The ring triggerring

m · tap

Enter — submit to Claude Code. (Quick tap: down–up within a second.)

m · hold

Command layer — ⌘ is held for you. D-pad → / ← steps through every open app (release m to land); D-pad ↑ / ↓ = ⌘PageUp/Dn, scrolling the terminal.

h · tapCycle app windowsthumb

⌘` — next window of the frontmost app (e.g. Terminal ⇆ Terminal). Bring it forward first.
